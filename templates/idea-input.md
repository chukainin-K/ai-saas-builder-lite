# Idea Input

このテンプレートは、AI SaaS Builder LiteにSaaS/アプリ案を入力するためのものです。

## 入力

```text
{{作りたいSaaSまたはアプリのアイデアを1から3文で書く}}
```

## 任意で追加するとよい情報

```markdown
## 対象ユーザー
{{誰向けのサービスか。未定なら空でよい}}

## 解決したい課題
{{どんな困りごとを解決したいか。未定なら空でよい}}

## 想定する利用シーン
{{いつ、どこで、どのように使われるか}}

## 制約
{{個人開発、予算、期間、使いたい技術など}}

## 出力してほしい成果物
- research-report.md
- product-spec.md
- development-tasks.md
- final-report.md
```

## 記入例

```markdown
## 入力
ペットの健康状態を記録し、通院履歴やワクチン予定を管理できるアプリを作りたい。

## 対象ユーザー
犬や猫を飼っている個人、複数匹を管理している家庭。

## 解決したい課題
通院履歴、薬、ワクチン予定が紙やメモアプリに分散して忘れやすい。

## 制約
まずは個人開発で作れるMVPにしたい。
```
